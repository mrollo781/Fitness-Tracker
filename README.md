# C++ Terminal Fitness Tracker 🚧 (Work in Progress)

Currently in active development! This project is a standalone C++ command-line application being built to handle the daily grind of tracking nutrition and gym progress without the bloat, ads, or paywalls of modern mobile apps. The goal is to create a lightweight, fast, and entirely local tool to stay on top of fitness goals directly from the terminal. 

## Planned Features
* **Calorie & Macro Management:** A core system to log daily meals and keep a strict eye on total intake, specifically dialing in on daily protein targets (e.g., hitting 140g+) alongside fats and carbs.
* **Exercise & Split Tracking:** A module built to log specific routines, track weight progression, and manage a structured 4-day training split (Push, Pull, Legs & Core, Upper/Aesthetic).
* **Hydration & Supplements:** Simple daily trackers to monitor water intake and log daily supplementation like creatine.
* **Local Data Storage:** Utilizing C++ file stream (`<fstream>`) operations to securely save and load daily logs straight to the hard drive so no data is ever lost.

Check back soon as the core C++ structs and terminal loops are currently being written!
